# PIXIU ARB

PIXIU ARB 的公开稳定版发布仓库。

**当前状态：首个稳定版本准备中。** 本仓库目前仅包含项目说明和许可证，尚未发布终端源码、安装包或可运行版本。

计划提供两种自托管使用方式：

- 本地电脑运行后台，通过本地浏览器操作。
- 自有云服务器运行后台，通过 SSH 隧道在本地浏览器操作。

稳定版本将经过源码与公开资料审查、自动化验证及安装验收后发布，包含对应源码、用户说明、安装包和校验文件。
