# Security policy

Security fixes apply to the PIXIU ARB version and commit identified in the relevant release. Upstream release history does not establish this project's behavior.

Use the repository Security tab for private vulnerability reporting. If unavailable, open a minimal issue asking for a private contact channel. Include no credentials, account identifiers, database files or exploit details.

Identify the version, safe reproduction conditions and business impact. Use synthetic data; never reproduce faults against another person's account or production funds.

The self-hosted terminal relies on the owner's operating system, credentials and network boundary. Report exchange infrastructure issues through the exchange security program. See [execution safety](docs/safety.md) and [deployment](docs/deployment.md).
