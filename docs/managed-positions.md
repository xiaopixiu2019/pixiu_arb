# 托管持仓与持续保护

新托管任务的启动确认同时授权本次稳定组的普通保证金保护和暂停期间持续保护。任务、接管、两腿归属及两项授权在首笔下单前原子保存；准备期间账户、权限、范围或撤权变化则创建失败并整体回滚，不留下半成品任务。

新建仓、接管平衡旧仓、追加及移交沿用稳定组身份，只有当前归属控制器可保护。已转交或完成的旧控制器不复活。未启用持仓管理的一次性任务不增加此授权。旧版或已有未覆盖组仍须经风险页明确授权，不扫描历史自动补权限。

登记不是执行资格。空仓或建仓中显示待核对，不把目标数量当成真实持仓。正常建仓由原执行器继续；暂停后须两次独立匹配的账户/持仓/订单快照以及有效保证金数据。仅根据接管基准和已确认成交账本处理实际减仓责任，未知提交或撤单只查原单、不重放。

程序重启保持普通交易 unset；原持续保护授权未撤销且核对可靠时可进入 protect_only。它仅允许受限只减仓保护，不能新增仓位或自动恢复普通任务。真实外部减仓、未知订单、账户或持仓不一致仍保留人工硬锁。

默认 Stop 保留仓位（KEEP）并停止自动保护；只有明确选择退出才请求平仓。明确只读或关闭持续保护会撤权并使排队许可失效。新的启动确认只授权本次组，不重新启用其他已撤权组；轮询、重启和普通恢复不授予新权限。已成交的配对责任保留，不因新增组或授权版本变化而丢失或重复。

风险页展示当前组数、已登记数、已核实保护数和未覆盖原因。数据过期不能继续显示已核实。通知开关独立，关闭通知不关闭保护。保证金规则和正常恢复见[保证金保护](margin-risk-management.md)；维护边界见[部署与恢复](deployment.md)。
