# 交易手续费统计

任务历史的最终收益使用独立的[任务净盈亏](task-performance.md)口径。这里的手续费是净盈亏分项，不能再从已包含费用的任务净额或账户净资产收益重复扣除。

资产管理主界面只展示累计交易手续费一个总体指标；对冲执行页保留任务费用明细、原始成交与账本核对入口。页面简化不减少后台证据或重复扣费。

持仓管理展示当前账户累计、今日、昨日、已归属任务及未归属费用；任务行展开建仓、平仓、调仓/保护、返佣/退费和交易所原币明细。账单及原始成交每页 25 条。此模块只读，不调整收益计算，不触发交易。

## 金额与归属

- 唯一金额来源为 CrossEx `account_book` 的 `TRADING_FEE`，成本 = `-change`。成交费用和订单费用不再相加。支出正数，返佣/退费扣减；净负值标为净返佣。不含资金费、利息、转账费及独立的强平费用类型。
- 汇率以费用时点附近 90 秒内的公共行情证据折算。USDT 是计价单位；USDC 等不得默认为 1。缺失汇率/冲突记录排除出已确认额并标记待核对，不能当作零。
- 当前账户通过凭据档案与已核实 user_id 的哈希隔离。任务归属必须匹配真实成交交易所、远端订单号、客户端订单号、合约及档案；账单记账池与成交交易所分别核验。`CROSSEX` 共享 USDT 账单只有在账单完整合约与已验证成交、持久化订单绑定一致且候选唯一时才能归属真实交易所；保留原始记账池和账单，不批量改名、不依据市场名称猜测，不把接管旧仓成本重复分配。冲突或未知记账池不猜测归属。
- 账户、任务及每腿共享费用覆盖检查；缺少另一腿的账单时保留该腿并标待核对。已确认金额与完整性分开表达，成交费用只核对账单，不重复计费。
- `fee_phase` 只记录本地订单的建仓、退出或调仓用途，不进入交易所请求或风控条件。旧订单无法证明用途时列为待分类。返佣未证明为 Maker 时不使用 Maker 标签。
- 任务小计覆盖当前标签的所有分页。账户累计包含手动交易和未归属费用，与当前标签无关；历史绑定在旧执行记录清理后保留。

## 覆盖与限制

每个账户自首次可信观察建立统计起点，不宣称补齐启用前历史。每分钟独立采集账本和原始成交，两者各自保存游标并重叠回读一分钟。已成交但费用/成交证据不足的订单另行轮转重核，按成交时点或订单创建至确认区间分为最多一分钟窗口；历史重核不代替最新窗口，不推进最新覆盖、不清除最新读取错误。每次固定窗口读取至末页，最多 25 页 × 200；超限、重复页、区间不符或上游错误不推进相应覆盖游标。长期离线超过分页上限或没有历史汇率时保持不完整，不推断完整合计。已有未估值账单仅用其费用时点附近已保存的可信汇率重算。

收益模块已通过净资产变化包含实际费用，本模块只是成本展示，不能再从累计收益中扣一次。当前资金费率年化仍沿用原算法，不是扣费后的实际投资回报预测。

## 与保证金保护的关系

本模块的真实费用/历史汇率口径保持精确；[保证金规划](margin-risk-management.md)中的美元币种约1:1只是执行前估算，不能用于补造账单或覆盖收益数据。正常账单延迟可显示待对账，不单独阻止已核实仓位/账户的下一批保护；未确认成本通过`margin_cost_reservations`继续占用预算，原订单/成交在预约未结时不参加历史清理。

`costAccounting`来自风险快照，表示预约而非实际费用，不能再次作为已确认费用加入累计手续费。真实成交或账本发生冲突、费用超预算仍按原风险核查处理。

## 本地接口与存储

- `GET /api/crossex/transaction-fees`：当前已核实账户汇总。
- `GET /api/crossex/transaction-fees/details?taskId=PAIR-…&page=1`：任务明细；不传 taskId 为账户账单。
- 必须带 `x-gct-read-intent: transaction-fees`，响应 `Cache-Control: no-store`；不接受任意账户参数或写入方法。原 `/api/crossex/fees` 费率接口不变。
- Migration `0026_transaction_fees.sql` 新增 fee_epochs/book/trades/order_bindings/rates 和 execution_orders.fee_phase；新增 `0027_fee_binding_coverage.sql` 保留已验证绑定的合约、期望成交量及订单时间，并保存普通成交的费用币种，以维持清理旧执行记录后的覆盖责任和原币展示。旧绑定缺少证明时不填零，继续待核对；历史成交币种缺失显示待核对，只有真实成交回报可补齐。不得修改已应用迁移或删除事实记录。
- 统计队列独立，30 秒超时，停止可取消；账户切换时丢弃旧响应。浏览器每 30 秒更新概览及展开明细，明细读取失败保留上次值并明示。费率页面/交易摘要/Boros 共用严格费率解析；空白不可用，实际零费率和负费返佣保留，缓存过期明示并刷新。

现行页面归属与财务显示见[账户收益统计](account-performance.md)；代码变更须以隔离账户和合成网关验证币种、符号、汇率、归属及重复数据边界。
