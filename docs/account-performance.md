# 资产管理与账户收益统计

## 页面及权限

资产管理沿用 `/portfolio` 和原资金状况布局：保证金概览下增加六项收益/费用指标及净资产走势，其后仍为交易所分布/余额、资金划转/资金记录、持仓及历史。旧 `/position-management` 兼容跳转至 `/portfolio`，独立页面已移除。右上角资产弹层与完整页复用同一个挂载视图；转换呈现形式不重置表单或增加一套统计轮询。对冲执行页按屏宽组合市场/费率与建仓/建仓后配置，执行摘要及策略自动化占满整行，复用原持仓、运行中、历史、日志、停止、恢复及平仓。其他策略页和风险管理页保留。

界面、配置及就地说明依据[对冲执行配置契约](hedge-execution-configuration.md)。正常解释可折叠，实际错误和关键风险直接显示；配置默认值、交易参数和停止 KEEP/EXIT 语义保持原逻辑。

账户收益和手续费统计只读交易所数据；浏览、切换图表及说明按钮不下单、撤单、转账或恢复实盘。资产页原有划转/平仓操作继续沿用各自权限与确认规则。后台采集失败只影响财务展示，不改变交易/风控状态。

## 统计口径

- 总资产：当前 CrossEx 账户全部可核实净权益，换算 USDT，不含 Gate 现货或其他账户。不以保证金余额代替净资产。
- Gate `assets[].equity` 为按币种的净权益，使用一次，不再重复扣负债或叠加浮盈。重复资产行、汇总行与同币种分账户行并存会阻断汇总。
- 非 USDT 使用公开现货价格，不假设 USDC/USD 等于 USDT。缺少换算价或隔离交易所模式未证明完整覆盖时显示不可用，不显示部分资产之和冒充总资产。
- 收益金额 = 期末净权益 − 期初净权益 − 净外部流入。CrossEx 内部划转不计外部资金流；Gate 现货与 CrossEx 之间计外部流入/流出。
- 累计收益率采用资金流时间加权的日段 Modified Dietz：`(E1−E0−ΣC)/(E0+Σ(w×C))`，逐日段连乘。分母不大于零或证据不完整时返回不可用。
- 当日/昨日按 UTC+8 日界线，存储时间 UTC。整分钟采样，以真实边界快照核算；首尾偏离日界线超过 60 秒标注“部分自然日”，说明中展示实际首尾时刻。首日中途启用不称完整自然日。
- 当前总年化复用 `calculatePortfolioFundingYield` 和共用Decimal资金费函数，是所有持仓当前资金费金额按显式汇率换算后简单年化合计除以新鲜账户保证金余额；不是单腿平均或历史总收益年化，不含未来价格盈亏、费用和滑点。顶部概览、完整页/弹层持仓表均传入当前profile的汇率证据；持仓范围查询复用30秒费率刷新，60秒过期或未来时间不可用。组资金费年化分母为该组实际起始保证金，不能用作账户总年化或替换经济退出净费率差。
- 双轴图左轴净资产 USDT、右轴累计收益率 %。时间窗只裁剪数据，不重置累计基准；缺口断线，当前年化不混入历史曲线。

公共持仓表已撤除强平价列、情景控件及专用API轮询。原始交易所 `liq_price`、保证金模式等字段仍保留，异常可选字段不阻断核心仓位更新。账户风险保护依据[保证金风控](margin-risk-management.md)，不使用历史强平价估算模型。

USD 估值采用 [Kraken 公开 USDT/USD 最近成交](https://docs.kraken.com/api-reference/market-data/get-recent-trades)的反向汇率，只接受 90 秒内且不在未来的正价格；公开请求不携带账户凭据、拒绝跳转，与其他币种 Gate spot 来源并行读取。失败保留 `missing_fx`，不设 USD=USDT，不倒填过去样本。

接口字段及分页语义依据：[Gate CrossEx 官方 API](https://www.gate.com/docs/developers/crossex/en/)；公开参考价使用 [Gate 现货 ticker](https://www.gate.com/docs/developers/apiv4/en/#retrieve-ticker-information)。公开文档不代替部署时对当前账户响应的核对。

## 采集和持久化

- 正常后台任务启用时每分钟独立采集，关页面不停止；前端每 30 秒读取统计。首次可信快照建立基准，不伪造启用前曲线。
- 生产客户端为定时统计创建独立只读请求队列，避免较慢的账本分页排在订单/核对请求之前；仍沿用固定交易所端点、签名及超时。公共币价请求不携带私有 API Key。
- 既有迁移 `0025_account_performance.sql` 创建 `performance_samples`、`performance_flows`、`performance_coverage`，不改旧迁移和原核对快照的 20 份保留规则。
- 账户键为 profile 与核实的交易所 user ID 的哈希。旧账户异步结果禁止落入新账户；身份无法核实时不返回旧账户缓存。
- 固定时间窗读账本和划转历史，直到短页。单次最多 25 页、每页 200 条；重复页、达到上限或超时都不算读完。
- 对账同时检查成功划转及相应账本：方向、币种、金额与时间。未知账务、未确认划转、匹配歧义、成功划转缺账本都会阻断收益计算。
- 资金流估值使用距离事件最近且不超过 90 秒的已保存公开价格；缺失历史换算价不使用查询时刻的价格倒填。
- 原始金融证据只保存于私有运行数据库，代码、文档与日志不存密钥或真实账户流水。曲线按展示周期降采样但保留缺口和首尾。

## 只读接口

`GET /api/crossex/performance?range=24h|7d|30d|all`

必须携带 `x-gct-read-intent: account-performance`。使用当前授权账户，拒绝任意 account/profile 参数；沿用 Host/Origin 校验，响应 `Cache-Control: no-store`。

响应含 `profileId`、`baselineAt`、`checkedAt`、`currency=USDT`、`timezone=Asia/Shanghai`；总资产、可用余额、累计收益/收益率、当日/昨日收益；曲线含时间、`equity` 与 `returnPct`。

指标值是十进制字符串或 `null`，附 `ready/partial/unavailable`、原因及真实统计首尾时刻。缺失不转换为零。

## 验证及上线限制

本地计算、隔离、分页和跨日测试使用临时数据库及合成网关；浏览器调用真实页面组件，合成响应仅在 e2e 文件内。本地验收不等于生产财务数据已核实。

统计表来自既有数据模型，不因页面迁移重建；页面变化不自动恢复实盘。上线须核对账户资产/币种范围、日界线与资金流水覆盖；隔离账户及缺少历史外币估值时仍须保持明确不可用。
