# 对冲执行配置与界面契约

适用于 `/strategies/paired-position`，依据维护中的 `strategy-route.tsx`、`position-management.tsx`、`position-management-config.ts`、`hedge-execution-summary.tsx`、`hedge-execution.css`、`positions-table.tsx` 和 `position-funding-yield.ts`。界面调整必须保留字段、条件显示、默认值、单位与计算行为；截图不作为默认值来源。

## 导航与行情口径

海力士溢价机器人入口位于“更多”，原 `/strategies/sk-hynix-premium` 路由、机器人行为和任务操作保留；“策略”菜单保留跨交易所对冲。资金费率页初始采用 APR、最大套利降序，在全部过滤结果上排序后分页。实时数值刷新不移动已应用的行顺序；点击列头、改变费率周期或筛选条件、点击“更新排序”时重新排名，翻页沿用该全局顺序。筛选成员变化和行情缺失明确提示，完整契约见 [Integration](integration.md#scoped-public-market-reads-local-loading-optimization)。“最大套利”为统一周期后的资金费率差值，并非扣费后的净收益。

资金费率页按当前选择的多空两腿、执行页按当前交易方向，使用相同公式：`(空腿最优买价 - 多腿最优卖价) / 多腿最优卖价 × 10000`。反向交易重新选取相反买卖盘，不直接将价差取负。报价缺失、交叉、资产单位不一致或过期显示“—”；两页采样时刻不同可能存在差异。执行页优先使用有效且新鲜的精确合约 WS 双边报价，否则读取独立 REST 报价作参考，不使用 last/mark price 补缺。REST 报价不解除实际交易的 WS/风险/权限检查，不改变 Maker 成交路径、退出口径及下列 23 项配置。完整数据契约见 [Integration](integration.md#scoped-public-market-reads-local-loading-optimization)。

## 必须保留的 23 项独立配置

杠杆按钮、摘要、持仓限额和提交共用当前账户/合约的已确认值；禁止把超限 8 倍截成 6 倍显示。超限/读取失败/应用中阻止新开仓，用户明确应用并取得确认后才同步新值；不确定写入先只读重查，不自动重放。只减仓不依赖新增杠杆许可，提交省略杠杆字段。策略杠杆浮层按视觉视口定位、边缘翻转和内部滚动，支持键盘进入、循环及 Escape 返回。

切换平台或刷新目录不得静默改变用户选定合约。不支持当前合约的平台禁用并标明未上市；目录未就绪或原合约不可用时保留原选择并阻止启动，不改选 AAVE 或任何首项。组合、数量、杠杆或交易权限变化会作废旧启动确认，最后确认再次检查当前资格。

新建对冲仓位草稿默认值为：挂单–吃单；退出价差 −90 bps、净资金费率年化阈值 −150%、关系 OR（任一满足）、持续 3000 秒。仅作用于本页初始草稿，保留手动选择；自动价差页面分别保留自己的执行方式草稿，其他策略及后端 schema 默认不变。已有任务配置不回填或迁移。

## 不属于配置、但不能丢失的展示和操作

- 市场：最优价格、资金费率/8h、可用或共享保证金、当前价差、行情缺失/过期状态。
- 费率分析：优势、当前优势年化、24H/7D/30D 历史累计费率、三个周期按钮、现有曲线/图例和加载错误状态。
- 校验：最小数量、保证金含 10% 预留、可用保证金、杠杆档位风险限额、预计仓位、未满足入场状态；新增合约风险还核实全仓能力和实际模式，未知或不合格腿直接显示原因并阻止启动。
- 执行摘要及最终确认：方向、数量、杠杆、只减仓、执行方式/挂单腿、费用、最大允许仓位、预计仓位、接管范围、管理规则和失衡保护；说明新托管任务启动同时登记本组IMR/MMR减仓授权，覆盖接管和新增的合并仓位；执行仍受原资格与数据门禁约束，旧任务授权在风险页单独管理。摘要可紧凑，完整确认不可删项。
- 启动按钮全部禁用/锁定原因、启动进度及成功/失败消息。
- 执行摘要之后的策略自动化：持仓表、日志、运行状态、历史分页、止盈编辑、停止、恢复、平仓及原安全确认。资产页复用公共持仓表。

## “!”说明交互规范

1. 使用小圆圈感叹号，正常为中性灰蓝，不用告警橙色；位于指标/字段标签后 6–8px。命中区域至少 24×24 CSS px，移动端 32×32。
2. 点击、触屏或 Enter/Space 打开锚定式说明浮层；Escape、点击外部或再次点击关闭。支持焦点返回、`aria-expanded`、有名称的说明按钮及说明内容关联。不能只依赖 hover/title。
3. 不遮挡正在填写的输入框；临近边缘自动翻转；小屏改为底部说明面板。打开说明不会切换复选框、提交表单或修改字段值。
4. 一次仅显示一条说明。内容顺序为“是什么 → 如何计算/何时生效 → 数据来源或风险”，公式仅在必要时展示。
5. 常规规则解释可进入说明浮层；实时错误、风险暂停、订单未知及实际任务停止后无自动保护的状态必须直接展示。旧仓接管开关保持明确标识，接管与保护授权范围继续在原有最终确认中完整展示。

## 指标与配置的分工

资产页的净资产、累计收益率、当前资金费年化、今日/昨日收益及双轴图遵守[账户收益统计](account-performance.md)，手续费遵守[费用统计](transaction-fees.md)，本配置清单不重复定义公式或图表配色。托管退出年化阈值的含义遵守[托管持仓规格](managed-positions.md)，不能替换成账户历史收益年化。

## 页面与模块归属

资产管理及其弹层沿用 `/portfolio`，收益和费用口径见[账户收益统计](account-performance.md)与[手续费统计](transaction-fees.md)。独立持仓管理页已移除，旧 URL 只保留兼容跳转；仍使用的 `position-management.tsx`、配置和相关测试不能因名称相同而删除。

完整资产页、弹层及执行页持仓表都使用同一组收益/汇率口径；强平价列和情景控制已撤除。账户保护参数不增加到上述23项任务配置，统一在[风险管理页](margin-risk-management.md)维护。

布局变更按[本地开发](local-development.md)运行响应式、表单持久性和完整流程验证。
